Antes de empezar

En este problem set pondrás en práctica lo aprendido en la sesión 1 y, sobre todo, en la sesión 2 sobre el mismo archivo de la General Social Survey (encuesta_social.csv), pero respondiendo a una pregunta distinta a la de clase: ¿varían las horas diarias de televisión según el estado civil y entre los años 2000 y 2014?

  1. Abre tu proyecto taller_R haciendo doble clic en taller_R.Rproj y comprueba que encuesta_social.csv está dentro de datos/.
  2. Trabaja en tu documento Quarto (.qmd) dentro de un apartado nuevo titulado Práctica de la sesión 2 (o en un archivo nuevo dentro de taller_R).
  3. Sigue los ejercicios en orden: cada paso reutiliza la tabla de trabajo datos_tv del anterior, dejando siempre intactos datos y el CSV original. Si te atascas, abre primero la pista y usa la solución para comprobar tu resultado.

Puedes consultar el cuaderno de la sesión 2 y las diapositivas de clase.

5. Transforma y clasifica el consumo con mutate() y case_when()

  1. Actualiza datos_tv con mutate() para añadir dos columnas nuevas:
    • tv_minutos: pasa horas_tv a minutos multiplicando por 60.
    • intensidad_tv: clasifica cada respuesta con case_when() en tres tramos: "Baja (0–1 h)" si horas_tv <= 1, "Media (2–3 h)" si horas_tv <= 3, y "Alta (4 h o más)" para el resto (TRUE).
  2. Comprueba dim(datos_tv) y muestra las tres primeras filas con head(datos_tv, n = 3).
  3. Responde en una frase: si una persona ve 2 horas diarias de televisión, ¿por qué basta con escribir horas_tv <= 3 sin poner horas_tv >= 2? ¿Y en qué grupo entra quien declaró 0 horas?
Ver pista

Puedes crear varias columnas separadas por coma dentro del mismo mutate(). Recuerda que case_when() evalúa las condiciones de arriba abajo y asigna la primera que se cumpla.

Ver solución 
# Añade tv_minutos e intensidad_tv dentro de mutate()
datos_tv <- datos_tv |>
  mutate(
    tv_minutos = horas_tv * 60,
    intensidad_tv = case_when(
      horas_tv <= 1 ~ "Baja (0–1 h)",
      horas_tv <= 3 ~ "Media (2–3 h)",
      TRUE          ~ "Alta (4 h o más)"
    )
  )

    • casadas: personas con estado_civil == "Married".

  3. Comprueba cuántas filas tiene cada tabla con nrow() y calcula la media redondeada de tv_minutos en cada una usando $, mean() y round(). Escribe una frase con tu conclusión.

Dos retos opcionales

Reto 1: encuentra los dos errores al filtrar

Alguien intentó filtrar datos_tv de estas dos maneras y obtuvo resultados inesperados:

# Intento A
datos_tv |>
  filter(estado_civil == c("Never married", "Divorced"))

# Intento B
datos_tv |>
  filter(estado_civil = "Married")

Explica qué falla en cada intento y escribe el código corregido para ambos.

Ver solución
  • Intento A: == no sirve para buscar varias categorías en c(...); R va alternando fila a fila ("Never married" en la fila 1, "Divorced" en la fila 2, etc.), lanza un aviso y devuelve solo 2.407 filas en lugar de las 4.763 reales. La forma correcta usa %in%.
  • Intento B: un solo = sirve para asignar un argumento dentro de una función, no para comparar valores. dplyr devuelve el error We detected a named input y pregunta si querías escribir estado_civil == "Married".
# Corrección del intento A
datos_tv |>
  filter(estado_civil %in% c("Never married", "Divorced"))

# Corrección del intento B
datos_tv |>
  filter(estado_civil == "Married")
